# Мобильная главная ALEX LAB — спецификация реализации

Источник макета: Figma `Ho1FCasrcIfitKInlPy86v`, страница `0:1`.

Этот файл является рабочей картой мобильной главной. Геометрия добавляется только после чтения соответствующего узла через Figma Bridge и проверки экспортированного скриншота.

## Общая механика

- При первом открытии мобильной главной показывается первый слайд: «Тест на аллергию ALEX² — один анализ, который даёт ответы».
- Меню не должно быть открыто при первом входе.
- Внизу слайдов находится мобильная панель: кнопка записи на тест и кнопка-бургер.
- Бургер открывает уже свёрстанное полноэкранное мобильное меню.
- «Закрыть» в меню возвращает пользователя к текущему слайду, не сбрасывая позицию.
- Десктоп продолжает использовать видео из `public/videos/scroll`.
- Мобильная версия для пациентов использует `public/videos/PHONE NAREZKA` для переходов 1–3 и `public/videos/MOB` для переходов 4–12.
- Мобильная версия для врачей использует отдельный комплект `public/videos/MOB FOR DOC`.
- Десктопная версия для врачей продолжает использовать `public/videos/rezak previs for doc`.

Все проверенные мобильные файлы имеют размер 1080×1920, H.264, 30 fps. Врачебный комплект содержит прямые и обратные переходы `s1…s12`; обратный переход `s3r` воспроизводится с тем же ускорением, что и на десктопе.
